## 军训篇

作者与 H 同学当时都担任军训负责人，接触比较多。军训第一天，他就问出了「报告，我该叫您老师还是教官」这样的问题。当时还以为他纯粹没有军训经验；到了训练时，说话必定要加「报告」，频率高得吓人。正巧那阵子 AI 视频很火，H 同学便得了个「报告哥」的外号。

至于报告的内容，包括但不限于：「报告教官，我动作慢了」「报告教官，能做到」「报告教官，系鞋带」……

在军训场外，H 同学也差不多：每次去辅导员办公室，必然是进门先喊报告，再给导员敬一个军礼。

当然，这些都只是「报告」的一面，除了给大伙添点乐子，没影响到别人。真正让我意识到他生活常识比较特别的，是下面这件事。

众所周知，大一的教材是负责人去搬运的。当时我们图省事，和隔壁班合租了一辆三轮车。前一天晚上，另外三人都和 H 同学确认了行程，他表示收到。到了当天，我们分头行动前往教材科，却发现 H 同学没有赶到；打电话询问，他说正在赶来。过了十分钟再问，回答说找不到路。

到这儿我还以为他只是不认路，于是把定位发给他。十分钟后再问——他说没用导航，不会用。这时候我已经意识到事情不对了：364 本书，另外两人还是女生。

把书骑车送回去之后，更离谱的来了：叫他下来帮忙清点、整理秩序，他确实下来了，领走了一套他室友的教材，然后就走了——像什么都没发生一样，回了寝室。

原本还有实弹射击那段时间的事……不过我想先开下一篇。
